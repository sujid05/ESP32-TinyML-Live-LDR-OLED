# ESP32-TinyML-Live-LDR-OLED
Real-time TinyML application on ESP32. Interfaces an LDR sensor on GPIO 34 and feeds scaled live ambient light values into an on-device TensorFlow Lite Micro model. Predicts Dark, Normal, or Bright categories and displays real-time predictions with confidence levels on an SSD1306 OLED display. Simulated on Wokwi.
